# Triagem — Grupo J.Macedo

Sistema de Triagem do Grupo J.Macedo Eletrônica.

## Estrutura

```
index.html        -> tela de login
painel.html       -> página após o login (protegida)
css/style.css     -> visual
js/config.js      -> chaves do Supabase (editar!)
js/login.js       -> lógica do login
img/              -> logo e ícone
```

## Tecnologias
- HTML, CSS e JavaScript puro (sem instalação)
- Supabase (autenticação)
- Vercel (hospedagem)

## Login
Usuários entram no padrão `nome.sobrenome`. No Supabase, o usuário é cadastrado
como `nome.sobrenome@triagem.jmacedo`.
